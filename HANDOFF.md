## Следующий шаг

**i18n финальная зачистка `lib/`** (маленький промпт): карта ошибок распознавания фото в `lib/receiptImage.ts` и сообщение ошибки курса НБС в `lib/fx.ts`, которое показывается на экране ревью. Приём тот же, что с `authErrors`/`db`: чистый модуль принимает `t`/возвращает ключи или отдаёт код ошибки, а строку резолвит экран. После этого **русских утечек ноль** → приложение полностью двуязычное и **готово к деплою** (на деплое заштамповать `[Unreleased]` датой и открыть новый пустой — по правилу в `AGENTS.md`).

## Открытые решения и риски

- **Чистые модули + i18n:** функция без доступа к хуку принимает `t: Translate` параметром и возвращает ключи (образец — `lib/authErrors.ts` `localizedAuthError`); либо возвращает код, а экран резолвит через `t`. Строки отображения не должны жить в `lib/` (как был фолбэк «Без места»).
- **История проекта:** `CHANGELOG.md` append-only; `HANDOFF.md` переписывается каждый виток — оба тем же коммитом (правило в `AGENTS.md`). Деплой — единственный ручной момент со штампом даты.
- **Паттерн i18n (повторять):** строки через `t()` из `useLanguage()`; форматтеры дат чистые, `locale` передаёт вызывающий, дефолт `'ru'`; plural-ключи звать с `{ count }`, русские `one`-строки содержат `{{count}}`; переиспользовать существующие ключи; модульные массивы меток держать как ключи и резолвить в рендере.
- **Jest + нативные модули:** тест, транзитивно импортящий экран/компонент с `LanguageContext`, грузит AsyncStorage; закрыто моком `__mocks__/@react-native-async-storage/async-storage.js`.

## Не трогать

- Агрегацию аналитики, тотал-эквивалентность, FX и денежную математику (целые центы) — правили только строки и один `null`-фолбэк.
- Прошлые записи `CHANGELOG.md` (append-only) и backfilled блоки Redesign / Foundation.
- Применённые миграции Supabase; RLS-инварианты; `lib/fx.ts` аналитика читает сохранённые суммы.
- Структуру ленты главной: `FlatList` из карточек по дням, нестики-заголовки — не возвращать `SectionList`/sticky.
- Русскую словарную лексику дат в `lib/dates.ts` (для `ru`) и языконейтральные строки/символы/эмодзи (`×N`, `≈ € · ≈ $`, `←`, `‹`/`›`, 🔒/🔁, латинский `Email`, URL-плейсхолдер скана) — намеренно без ключей.
- Серверный фетч страницы чека (качает устройство, Edge Function только парсит).
