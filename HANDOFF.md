## Открытые решения и риски

- Сортировка общая для вкладок категорий и мест и сохраняется при переключении между ними; top-6 и цвета намеренно пересчитываются из текущего порядка.
- «Прочее» остаётся агрегатом без drilldown; раскрытие показывает исходные строки 7+ и сохраняет их собственный drilldown.
- Темп для завершённых/произвольных периодов — итог / inclusive число дней диапазона; прогноз существует только для незавершённого текущего месяца.
- Производные средние и прогноз округляются до целых копеек только при отображении; сохранённые суммы и FX не меняются.
- Analytics остаётся read-only и читает сохранённые `amount_rsd/usd/eur`; period/range API из #1–#2 не менялся.
- Windows Application Control по-прежнему может блокировать `hermesc.exe`; JS Android bundle проверяется через `--no-bytecode`.
