## Открытые решения и риски

- **Чистые модули + i18n:** функция без доступа к хуку принимает `t: Translate` параметром и возвращает ключи; локаль прокидывает вызывающий экран из `useLanguage()`. Образец — `lib/authErrors.ts` (`localizedAuthError`).
- **История проекта:** `CHANGELOG.md` append-only (прошлые записи не редактировать), одна запись на задачу под `## [Unreleased]`; `HANDOFF.md` переписывается каждый виток — оба тем же коммитом (правило в `AGENTS.md`). Деплой — единственный ручной момент: заштамповать `[Unreleased]` датой и открыть новый пустой.
- **Паттерн i18n (повторять):** строки через `t()` из `useLanguage()`; форматтеры дат чистые, `locale` передаёт вызывающий, дефолт `'ru'`; plural-ключи звать с `{ count }`, русские `one`-строки содержат `{{count}}`; переиспользовать существующие ключи вместо дублей.
- **Jest + нативные модули:** тест, транзитивно импортящий экран/компонент с `LanguageContext`, грузит AsyncStorage; закрыто моком `__mocks__/@react-native-async-storage/async-storage.js`.
