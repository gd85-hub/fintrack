## Открытые решения и риски

- **История проекта (новое):** `CHANGELOG.md` — append-only, прошлые записи не редактировать; одна запись на задачу под `## [Unreleased]`. Деплой (EAS web+Android) — единственный ручной момент: заштамповать `[Unreleased]` датой и открыть новый пустой сверху (делать только при реальном деплое или по указанию промпта).
- **Паттерн i18n (повторять):** строки — через `t()` из `useLanguage()`; форматтеры дат чистые, `locale` передаёт вызывающий, дефолт `'ru'`; plural-ключи звать с `{ count }`, русские `one`-строки содержат `{{count}}`. Переиспускать существующие ключи (`add.*`, `common.*`) вместо дублей.
- **Jest + нативные модули:** тест, транзитивно импортящий экран/компонент с `LanguageContext`, грузит AsyncStorage; закрыто моком `__mocks__/@react-native-async-storage/async-storage.js`.
- **Холодный старт на English:** `i18n.locale` ставится эффектом в `LanguageProvider` после первого рендера; на первом кадре при активном EN возможна краткая русская plural-ветка. Косметика.

## Не трогать

- Прошлые записи `CHANGELOG.md` (append-only) и backfilled блоки Redesign / Foundation.
- Применённые миграции Supabase; RLS-инварианты; денежную математику (целые центы) и FX-инварианты (`lib/fx.ts`, аналитика читает сохранённые суммы).
- Структуру ленты главной: `FlatList` из карточек по дням, нестики-заголовки — не возвращать `SectionList`/sticky, не восстанавливать селектор валюты и стрелки месяца на главной.
- Русскую словарную лексику дат в `lib/dates.ts` (нужна для `ru`) и языконейтральные строки (`×N`, hero-эквиваленты `≈ € · ≈ $`, `←`, URL-плейсхолдер скана) — намеренно без ключей.
- Серверный фетч страницы чека (качает устройство, Edge Function только парсит). `ReceiptCamera.web.tsx` / `ReceiptImageInput.tsx` — без строк, не трогать в i18n-витках.
