## Открытые решения и риски

- Цвет категории/места намеренно зависит от позиции в текущем рейтинге: это жертвует identity-stable цветом ради максимальной различимости top-7 в каждом снимке.
- «Прочее» — только агрегат без drilldown; раскрытие показывает исходные строки 8+ и сохраняет их собственный drilldown.
- Сумма ShareBar и collapsed-списка сохраняет полный итог: «Прочее» считается как точный remainder после top-7, без повторной FX-конвертации.
- Analytics остаётся read-only и читает сохранённые `amount_rsd/usd/eur`; period/range API из #1–#2 не менялся.
- Windows Application Control по-прежнему может блокировать `hermesc.exe`; JS Android bundle проверяется через `--no-bytecode`.
