## Открытые решения и риски

- Цвет категории/места зависит от позиции в текущем рейтинге: это жертвует identity-stable цветом ради различимости top-6 в каждом снимке, но палитра остаётся измеренным шестицветным набором DS.
- «Прочее» — только агрегат без drilldown; раскрытие показывает исходные строки 7+ и сохраняет их собственный drilldown.
- Сумма ShareBar и collapsed-списка сохраняет полный итог: «Прочее» считается как точный remainder после top-6, без повторной FX-конвертации.
- Analytics остаётся read-only и читает сохранённые `amount_rsd/usd/eur`; period/range API из #1–#2 не менялся.
- Windows Application Control по-прежнему может блокировать `hermesc.exe`; JS Android bundle проверяется через `--no-bytecode`.
