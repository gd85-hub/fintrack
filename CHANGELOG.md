# Changelog

Заметные изменения Fintrack. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

Правила ведения — в `AGENTS.md` → «Project history files». Коротко: файл **append-only** (прошлые записи не редактируются), одна запись на задачу под `## [Unreleased]` в бакете **Added / Changed / Fixed**; запись описывает изменение **для пользователя**, заканчивается хэшем коммита и, если у задачи было решение, — клаузой `— why: …` (её майнит дизайн-кейс). `[Unreleased]` — смёрджено, но ещё не в выпущенной сборке; при деплое (EAS web + Android) блок штампуется датой, а сверху открывается новый пустой `[Unreleased]`.

История до заведения этого файла (блоки **Redesign** и **Foundation**) собрана ретроспективно из git-лога и датирована по тому, когда работа легла в `main`, а не обязательно по деплою.

## [Unreleased]

### Added
- Выбор периода в аналитике: Этот/Прошлый месяц, Последние 3 месяца, Этот год и свой диапазон дат — вместо только помесячного просмотра. — why: один месяц в вакууме мало говорит; произвольные периоды дают реальную картину трат.
- Внутренняя поддержка произвольных периодов в аналитике (range-запросы по категориям, местам и тратам); месячные функции делегируют в общее ядро. — why: фундамент под выбор периода в аналитике (последние 3 месяца, год, свой диапазон), без изменения текущего поведения.
- PDF-экспорт стал оформленной выпиской за месяц: шапка, итог с эквивалентами в EUR/USD, плитки (операции, средний чек, дни с тратами, крупнейшая трата), разбор по категориям с полосами и детализация по дням. — why: таблицы мало — выписка должна быть наглядной и читаться с одного взгляда.
- Тёмная тема: переключатель Система / Светлая / Тёмная в Settings, значения из Figma DS, живое переключение и персист. — why: завершение темизации — всё приложение читает цвет из useColors, осталось дать пользователю выбор.
- `HANDOFF.md` — ephemeral-состояние проекта в корне репозитория для бесшовной передачи витка между Claude Code и Codex. `b13af18` — why: проект ведётся двумя ИИ по очереди (у обоих кончаются лимиты), поэтому нужен общий носитель «где мы / что дальше», который автоматически читают оба исполнителя.
- История проекта: заведён `CHANGELOG.md` (backfill из git-лога), правило ведения HANDOFF/CHANGELOG закреплено в `AGENTS.md`. — why: раньше оба файла обновлялись только потому, что каждый промпт это просил; как правило в законе проекта их теперь ведёт любой агент автоматически, и история остаётся богатой решениями для дизайн-кейса.
- Слой экспорта трат: чистые билдеры CSV / Excel / PDF (lib/export) с тестами — основа для выгрузки в Reports. — why: мостит приложение к привычному табличному workflow; формат-агностичный пласт отделён от UI и нативных модулей.
- Экспорт трат за месяц в CSV, Excel и PDF с «поделиться» на вкладке Reports (пустой таб стал рабочим). — why: мостит приложение к привычному табличному workflow — выгрузка в удобный формат без смены привычек.
- Фундамент тёмной темы: светлая и тёмная семантические палитры (значения из Figma DS), ThemeProvider и хук useColors. — why: тёмная тема уже существует в дизайн-системе модами переменных — переносим её значения, а не придумываем.

- Внутренний рефакторинг: data-слой lib/db.ts (2462 строки) разбит на модули lib/db/ по доменам за бочкой-реэкспортом. Поведение и публичный API не изменились. — why: монолит мешал развивать бэк; расчистка перед бюджетами и повторяющимися тратами.
- Экран ревью чека и редактор траты читают цвета из useColors — миграция на динамическую тему завершена (всё приложение читает цвет из хука). — why: последние экраны; дальше остаётся включить переключатель темы.
- Аналитика (включая цвета графиков), экран сканирования чека и авторизация читают цвета из useColors; легаси переведён на семантику. — why: перенос экранов на динамическую тему.
- Экраны управления категориями и местами читают цвета из useColors; легаси переведён на семантику. — why: перенос экранов на динамическую тему.
- Главная, Settings и Reports читают цвета из useColors; легаси переведён на семантику. — why: перенос экранов на динамическую тему.
- Пикеры и инпуты (категория, место, дата, валюта, выбор фото, камера, mini-row) читают цвета из useColors; легаси переведён на семантику. — why: продолжаем перенос на динамическую тему.

### Fixed
- Аналитика: откат ошибочной подмены категориальной палитры — вернулись выверенные (CIEDE2000/Machado) шесть цветов DS; разбивка показывает топ-6 + «Прочее». — why: прошлый коммит случайно прогнал устаревший промпт и заменил палитру на невалидированную; выверенные цвета трогать нельзя.
- Экспорт PDF на вебе: в диалог печати уходит сама выписка, а не страница приложения. — why: expo-print на вебе печатал текущий документ; теперь HTML рендерится в изолированном скрытом iframe и печатается он.
- Стрелка «назад» в управлении категориями и местами возвращает в Settings, а не на Home. — why: router.back() в таб-стеке падал на корень вкладки (Home).
- Локализованы пропущенные поверхности: выбор фото чека (native + web), a11y-подпись возврата в DS List Row и заглушка вкладки Reports. — why: platform-split и DS-компоненты проскочили поэкранные i18n-проходы; Reports была захардкожена по-английски.
- Системные категории, группы и типы мест переводятся на английский через слой отображения (lib/catalog), пользовательские названия не трогаются. — why: сид-данные в БД по-русски; переводим на показе, без миграции и без изменения данных.

## Foundation — рабочее приложение до редизайна (2026-07 … 2026-09)
Фазы 0–6 (подробнее — `README.md`). Трекер личных расходов: Expo (React Native) + TypeScript; бэкенд Supabase (Postgres с RLS, Auth, Edge Functions на Deno). Деньги — целые копейки, half-up; каждая трата хранится в оригинальной валюте и сконвертированной в RSD/USD/EUR по курсу НБС на дату траты (заморожено на запись).
