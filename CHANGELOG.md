# Changelog

Заметные изменения Fintrack. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

Правила ведения — в `AGENTS.md` → «Project history files». Коротко: файл **append-only** (прошлые записи не редактируются), одна запись на задачу под `## [Unreleased]` в бакете **Added / Changed / Fixed**; запись описывает изменение **для пользователя**, заканчивается хэшем коммита и, если у задачи было решение, — клаузой `— why: …` (её майнит дизайн-кейс). `[Unreleased]` — смёрджено, но ещё не в выпущенной сборке; при деплое (EAS web + Android) блок штампуется датой, а сверху открывается новый пустой `[Unreleased]`.

История до заведения этого файла (блоки **Redesign** и **Foundation**) собрана ретроспективно из git-лога и датирована по тому, когда работа легла в `main`, а не обязательно по деплою.

## [Unreleased]

### Added
- `HANDOFF.md` — ephemeral-состояние проекта в корне репозитория для бесшовной передачи витка между Claude Code и Codex. `b13af18` — why: проект ведётся двумя ИИ по очереди (у обоих кончаются лимиты), поэтому нужен общий носитель «где мы / что дальше», который автоматически читают оба исполнителя.
- История проекта: заведён `CHANGELOG.md` (backfill из git-лога), правило ведения HANDOFF/CHANGELOG закреплено в `AGENTS.md`. — why: раньше оба файла обновлялись только потому, что каждый промпт это просил; как правило в законе проекта их теперь ведёт любой агент автоматически, и история остаётся богатой решениями для дизайн-кейса.

### Changed
- Поэкранная локализация интерфейса (RU/EN) с живым переключением языка и персистом выбора; форматирование дат стало locale-aware (английский UI больше не показывает русские месяцы/дни недели), добавлены корректные русские склонения счётчиков. Переведены навигация и Settings `dd23e1d`, главный экран `c3b2fa1`, сканирование чека и камера `c275d6c`, экран ревью/правки чека `c4aea82`, общие пикеры (категория/место/дата/валюта) `a7cc62a`, ручной редактор траты `52b1cca`, управление категориями `b417abd` и местами `c1f6cca`. — why: приложение растёт в кроссплатформенный продукт и портфельный кейс, английский нужен для демо и неноминативных пользователей; замороженная локаль дат ломала смысл интерфейса при EN.
- Локализованы экраны авторизации (вход, регистрация, подтверждение email) и сообщения ошибок аутентификации. — why: вход — первый экран, который видит пользователь; завершаем двуязычие с точки входа.

- Локализованы последние пользовательские строки в lib: ошибки распознавания фото чека и сообщение о недоступности курсов в пути сохранения ревью. UI полностью двуязычный. — why: закрываем последние русские протечки перед деплоем.

## Foundation — рабочее приложение до редизайна (2026-07 … 2026-09)
Фазы 0–6 (подробнее — `README.md`). Трекер личных расходов: Expo (React Native) + TypeScript; бэкенд Supabase (Postgres с RLS, Auth, Edge Functions на Deno). Деньги — целые копейки, half-up; каждая трата хранится в оригинальной валюте и сконвертированной в RSD/USD/EUR по курсу НБС на дату траты (заморожено на запись).

### Added
- Phase 0 — каркас, схема БД, RLS на каждой пользовательской таблице, email-авторизация с персистом сессии. `7c6b40c`
- Phase 1 — ручной ввод трат в RSD/USD/EUR с NBS-конвертацией и живым превью трёх валют; экзотические валюты (KZT/RUB/TRY/др.) через ручной RSD-эквивалент. `95802c5` `f838237`
- Phase 2 — сканирование сербских фискальных чеков (SUF QR): устройство качает HTML, Edge Function парсит журнал; один чек → строка `receipts` + по трате на позицию; скан нативный, на web — плейсхолдер (CORS). `f7ab74a` `68f5616` `c6edfe6` `e19c76d`
- Phase 3 — распознавание фото/скриншотов чеков vision-моделью и текстовая категоризация позиций; персональный словарь категоризации (dictionary-first) и нормализация бренда мерчанта. `8fe7772` `35d1473` `428c475` `56afaf4` `d9ef612`
- Phase 4 — аналитика (read-only): разрезы по категориям и мерчантам/типам, drilldown с «показать ещё», переключатель валюты. `4cbf549` `bdadec5` `3cc314d`
- Phase 5 — единые разворачиваемые покупки на главной; управление категориями и местами (rename / merge / delete с переуказанием ссылок, системные записи защищены). `0afefb1` `7421df6` `9aa0dc9`
- Phase 6 — дистрибуция: Android preview-сборка (EAS) и веб-деплой (EAS Hosting, web output `single`). `6906a66`
